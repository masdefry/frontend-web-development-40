Setup Project React.js dengan Vite

    1. Membuat Project Baru

            npm create vite@latest

    2. Didalam Directory Project

            npm install

    3. Jalankan Project Vite

            npm run dev

Instalasi Dependencies

    ▪️ TailwindCSS (Langsung Lakukan Step-02 dan Seterusnya)

            https://tailwindcss.com/docs/installation/using-vite

    ▪️ DaisyUI

            1. Install daisyUI as a Node package:

                    npm i -D daisyui@latest

            2. Add daisyUI to index.css:

                    @plugin "daisyui";

    ▪️ React Router DOM

                npm i react-router@latest

    ▪️ React Icons

                npm i react-icons
